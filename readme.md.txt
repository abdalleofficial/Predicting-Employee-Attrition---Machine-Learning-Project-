# Employee Attrition Prediction

## Project Overview

Employee Attrition Prediction is a machine learning project that predicts whether an employee is likely to leave a company based on employee-related factors such as age, department, monthly income, job satisfaction, and years of experience.

The goal of this project is to help organizations identify employees at risk of leaving and support better employee retention strategies.

---

## Dataset

Dataset Source: Kaggle

Employee Attrition Prediction Dataset

The dataset contains employee information such as:

* Age
* Gender
* Department
* Job Role
* Monthly Income
* Years at Company
* Job Satisfaction
* Attrition Status

Target Variable:

* 0 = Employee Stays
* 1 = Employee Leaves

## Machine Learning Models

The following models were used:

### Logistic Regression

Used as a baseline classification model for employee attrition prediction.

### Random Forest Classifier

Used to improve prediction accuracy and compare performance with Logistic Regression.
